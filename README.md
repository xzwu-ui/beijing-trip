# 北京行纪 · 四日冬行攻略

2026.11.14 – 11.17 北京四日游攻略站：环球影城、什刹海、国贸 CBD、故宫。

单文件静态站（`index.html`），零构建零依赖：

- **抢票日历** —— 设定出发日后自动计算故宫/恭王府/天安门/天坛/环球每张票的开抢时刻
- **交互行程地图** —— Leaflet + 高德底图，四日动线分色连线，可在右侧面板增删点位、排序、地图选点，编辑存 localStorage
- **美食/打包清单** —— 可勾选，进度自动保存
- 三张随行参考地图（小红书创作者所有，仅作个人行程参考）
